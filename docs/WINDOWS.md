# Установка Гранки в Windows

Готовая поставка рассчитана на Windows 10/11 x64. Отдельно устанавливать Python,
Node.js или зависимости не нужно. Редактирование текста работает без аккаунта ИИ.

## Установщик

1. Скачайте `Granka-<версия>-Setup-x64.exe` со страницы релиза
   [andromanpro/granka](https://github.com/andromanpro/granka/releases).
2. Запустите установщик. Он устанавливает программу для текущего пользователя
   в `LocalAppData/Programs/Granka`, без прав администратора.
3. Откройте Гранку из меню Пуск. При желании включите ярлык на рабочем столе.
4. В библиотеке уже есть учебная статья с замечаниями и «Начало работы».
   Собственный текст можно открыть кнопкой **＋**.

Установщик не подписан цифровым сертификатом. Windows может показать
неизвестного издателя или предупреждение SmartScreen. Исходный код открыт,
а файл `SHA256SUMS.txt` позволяет сравнить скачанный файл с опубликованной
контрольной суммой. Контрольная сумма не заменяет подпись издателя.

## Вход в ИИ

В меню **Пуск → Гранка** есть команда **Войти в ChatGPT**. Она запускает
официальный вход Codex в браузере. После входа вернитесь в Гранку и нажмите
**Проверить текст**. Доступность и лимиты зависят от аккаунта; установка
программы не предоставляет подписку. Уже выполненный вход Codex используется
повторно. Гранка не получает пароль аккаунта.

Этот вход описан в [официальной документации OpenAI](https://learn.chatgpt.com/docs/developer-commands#codex-login).
OpenRouter остаётся отдельной настраиваемой интеграцией со своим ключом.
Распознавание голоса и публикация на свой сайт требуют дополнительной настройки.

## Переносимый ZIP

Распакуйте `Granka-<версия>-Portable-x64.zip` целиком и запустите **Granka.exe**.
Соседние папки `app`, `runtime` и `codex` нужны программе — переносите их вместе.
Вход и остановка доступны через `Войти в ChatGPT.cmd` и `Остановить Гранку.cmd`.
Архив не регистрирует программу в системе. Личные данные по-прежнему хранятся
в LocalAppData/Granka; «переносимый» здесь означает запуск без установки.

## Обновление и удаление

Сохраните текст во всех вкладках, дождитесь завершения заданий и выберите
**Пуск → Гранка → Остановить Гранку**. Затем запустите новый установщик
или удалите программу через настройки Windows. Работающий экземпляр
блокирует замену файлов; принудительное завершение не применяется.

Статьи, подключённые папки и личные настройки не удаляются. Настройки
установленной поставки находятся в `LocalAppData/Granka/granka-config.json`,
учебные материалы — в `LocalAppData/Granka/articles`. Собственные открытые
файлы остаются в выбранных пользователем папках.

## Сборка

На Windows x64 с Python 3.14:

```sh
python tools/windows/build.py --output _dist/windows
```

Скрипт использует закреплённые версии и SHA256 из `dependencies.lock.json`.
Python загружается из официального Windows-манифеста python.org, Codex — из
официального выпуска OpenAI. Переносимые файлы компилятора Inno Setup 6.7.3
берутся из пакета `Tools.InnoSetup` NuGet; установка компилятора в систему
не требуется. Можно передать собственный `--iscc /path/to/ISCC.exe`.
Нативный launcher собирается штатным C#-компилятором .NET Framework Windows.
Итоговая программа использует встроенный в Windows .NET Framework 4.x.

Состав приложения ограничен явным списком и проходит проверку публичных
файлов. Конфиг, токены, корпус, задания, Git-история и каталоги сборки
не включаются. Проверка негативными тестами подтверждает отказ при порче
загрузки, выходе архива за целевой каталог и личных данных в исходниках.

Обычная сборка требует чистое Git-дерево. Для локальной проверки допустим
`--allow-dirty`: файлы получают суффикс `candidate`, а манифест отмечает
`source_dirty: true`. Такой файл не следует выдавать за опубликованный релиз.
Скрипт не создаёт тег и не публикует файлы в GitHub. Сборка без сертификата
не пытается обойти проверки Windows.

Результат: установщик, переносимый ZIP, `SHA256SUMS.txt` и квитанция сборки.
Для проверки на отдельном каталоге состояния используйте
`tools/windows/smoke.py --payload <папка-Granka> --output <папка-отчёта>`.
