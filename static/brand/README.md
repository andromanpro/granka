# Знак Гранки

27.10.2026 автор выбрал направление **«Скобочки»**. Две светлые скобки и коралловая третья обозначают авторскую интонацию, которую редактор помогает сохранить.

| Файл | Где используется |
|---|---|
| `mark.svg` | Иконка со скобочками на графитовой плашке, интерфейс |
| `favicon.svg` | Компактная версия для вкладки браузера |
| `symbol.svg`, `symbol-ink.svg` | Знак без плашки для тёмного и светлого фона |
| `symbol-mono.svg`, `symbol-mono-ink.svg` | Одноцветные варианты знака |
| `logo.svg` | Словесный знак для тёмного фона |
| `logo-ink.svg` | Словесный знак для светлого фона |
| `logo-mono.svg`, `logo-mono-ink.svg` | Одноцветные логотипы |
| `app-icon.png` | Значок 512 × 512 |
| `granka.ico` | Ярлык и старые браузеры: 16, 24, 32, 48, 64, 128, 256 пикселей |
| `favicon-16.png`, `favicon-24.png`, `favicon-32.png` | Малые PNG в собственном разрешении |
| `icon-48.png`, `icon-64.png`, `icon-128.png`, `icon-256.png` | PNG для ярлыков и других размещений |
| `apple-touch-icon.png` | Значок 180 × 180 |

Цвета: графит `#252923`, светлый текст `#ece8d9`, коралл `#edb095`. На светлом фоне — тёмный текст `#263020` и терракота `#ae6249`.
Контуры слова «Гранка» получены из установленного Georgia; файл шрифта
не распространяется. SVG отображается без установленного шрифта.

Сборка из корня проекта: `python -B tools/build-brand.py`.
По умолчанию используются готовые SVG. Для изменения словесного знака
передайте свой локальный шрифт через `--font /path/to/font.ttf`.
Для растрирования нужны Playwright и Pillow; FontTools используется с `--font`.
ICO собирается из отдельно отрисованных размеров: мелкие значки не получаются простым уменьшением PNG512. Сборка проверяет состав ICO и точное совпадение его пикселей с соответствующими PNG.
